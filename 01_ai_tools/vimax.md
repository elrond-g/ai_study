# ViMax

港大（HKUDS）出品的 Agentic 视频生成框架，集导演、编剧、制片人和视频生成器于一体。利用多 Agent 协作实现端到端的智能视频创作。

## 核心特性

### 全角色 Agent 化
将传统视频制作的多个角色——导演（整体把控）、编剧（剧本创作）、制片人（资源协调）、视频生成器（画面生成）——全部 Agent 化，协同完成创作。

### 端到端生成
从创意到成品视频的一站式生成，无需人工干预每一步。

### 多 Agent 协作
各 Agent 角色间通过消息传递协调，导演 Agent 统筹全局，确保视频风格和叙事一致性。

## 技术架构

- **研究机构**：香港大学数据科学实验室（HKUDS）
- **架构**：Multi-Agent 协作框架
- **领域**：AI 视频生成 + Agent 协作
