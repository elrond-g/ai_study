# AI Engineering from Scratch

从零开始的 AI 工程系统课程。473 课、20 个阶段、约 320 小时，涵盖 Python / TypeScript / Rust / Julia 四种语言。每课产出可复用产物：Prompt、Skill、Agent、MCP Server。免费开源，MIT 许可。

## 核心特性

### 20 阶段系统课程
从线性代数到自主 Agent 群，分 20 个递进阶段：
```
Phase 0: 环境配置与工具
Phase 1-4: 数学基础 → 经典 ML → 深度学习
Phase 5-8: Transformer → LLM → 微调 → RLHF
Phase 9-12: RAG → Agent → MCP → 多 Agent
Phase 13-16: 生产部署 → 评估 → 安全 → 治理
Phase 17-19: 多模态 → 视频 → 前沿方向
```

### 从数学推导开始
每个算法先从原始数学推导实现：反向传播 → 分词器 → 注意力机制 → Agent 循环。先理解底层原理，再引入 PyTorch 等框架。

### 四语言实现
核心算法用 Python / TypeScript / Rust / Julia 四种语言分别实现，不同场景选择最佳语言。

### 实战导向
84% 的学生已经在用 AI 工具，但只有 18% 感觉有专业使用能力——这个课程旨在填补这一鸿沟。
