# Anthropic Cybersecurity Skills

最大的开源 AI Agent 网络安全技能库。754 个生产级安全技能，覆盖 26 个安全领域，映射到 MITRE ATT&CK、NIST CSF 2.0、MITRE ATLAS、D3FEND、NIST AI RMF 五大框架，支持 26+ AI 平台。

## 核心特性

### 754 个结构化安全技能
涵盖渗透测试、事件响应、数字取证、威胁狩猎、云安全、恶意软件分析等 26 个领域，每个技能遵循 agentskills.io 标准。

### 五框架映射
每项技能同时映射到：
- MITRE ATT&CK（攻击技术）
- NIST CSF 2.0（网络安全框架）
- MITRE ATLAS（AI 对抗威胁）
- D3FEND（防御技术）
- NIST AI RMF（AI 风险管理）

### 26+ 平台支持
Claude Code、GitHub Copilot、Codex CLI、Cursor、Gemini CLI、Hermes Agent 等。

### 给 AI 注入安全分析师能力
初级分析师知道哪些 Volatility3 插件用于内存取证、哪些 Sigma 规则检测 Kerberoasting、如何划定云泄露范围——这个仓库让 AI Agent 也掌握这些技能。
